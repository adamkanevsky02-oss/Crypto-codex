# Outbox

The weekly run writes one file in here each Monday — `2026-week-38.md` and so on.

Each file contains everything for that week, in review order:

1. **Follow-ups due** — people who didn't reply last time
2. **Cold emails** — drafted and ready, each with the company, the person, the
   address (flagged if it's a guess), and the full email
3. **Applications to submit** — links plus the tailored points to use

Read it top to bottom, change anything you don't like, then send the ones you
approve. Nothing goes out until you do.
